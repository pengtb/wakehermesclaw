# WakeHermesClaw

Превращает телефон в AI-ассистента, которого можно вызвать в любой момент: произнесите слово-активатор, нажмите плитку в быстрых настройках, удерживайте панель навигации или нажмите кнопку на гарнитуре — и голосовая панель поднимется; сказанное уходит на ваш бэкенд, запущенный на компьютере (Hermes Agent или OpenClaw), а ответ произносится вслух. Помимо разговора, ассистент умеет управлять самим телефоном — читать экран, нажимать, фотографировать, отправлять SMS, определять местоположение.

Это личная ветка, сделанная на основе [openclaw-assistant](https://github.com/yuga-hashimoto/openclaw-assistant); основная работа — подключить Hermes Agent и довести до конца голосовую цепочку, выбор бэкенда и управление телефоном.

- Последняя версия: v2.5.2 ([Releases](https://github.com/pengtb/wakehermesclaw/releases))
- Требования: Android 8.0 и выше (minSdk 26), targetSdk 34
- Языки интерфейса: 简体中文 / 繁體中文 / English / 日本語 / 한국어 / Deutsch / Español / Français / हिन्दी / Русский

## Что он делает

### Голосовой диалог

- **Четыре способа вызова**: слово-активатор, плитка в быстрых настройках, системный жест ассистента (удержание панели навигации / кнопки питания), статический шорткат приложения; можно также просто открыть в приложении «Голосовой диалог».
- **Непрерывный диалог**: после ответа приложение автоматически продолжает слушать; можно переключиться в режим рации — нажатие начинает запись, повторное нажатие завершает её и отправляет.
- **Слова выхода**: произнесите «退出», «exit» и подобное, чтобы сразу завершить диалог; слова по умолчанию зависят от языка интерфейса и меняются в настройках.
- **Панель не перекрывает уведомления**: голосовая панель — карточка, прижатая к низу, верхняя строка состояния остаётся системе, во время диалога можно по-прежнему открыть шторку уведомлений и подтвердить запрос.
- **Состояние в процессе**: на время диалога в строке состояния остаётся уведомление, нажатие на него возвращает к панели диалога; на переднем плане панель показывает «Голосовой диалог идёт», в фоне — «Нажмите, чтобы вернуться к голосовому диалогу», после окончания диалога уведомление исчезает само.

### Распознавание речи (STT)

Четыре бэкенда на выбор:

| Бэкенд | Описание |
| --- | --- |
| Системное распознавание | Встроенная служба распознавания телефона, нулевая настройка |
| OpenAI-совместимый | Свой сервис `/v1/audio/transcriptions`, пакетная загрузка |
| FunASR (потоковый) | Локальный FunASR, текст появляется по мере речи |
| Huawei HMS (ML Kit) | Распознавание на устройстве, нужны HMS Core и API Key из AGC; **поддерживаются только китайский и английский** |

В цепочке распознавания есть две подстраховки: таймаут тишины, когда во всём фрагменте нет текста, и дополнительное завершение на стороне клиента, если SDK Huawei не вызывает колбэк на финальном кадре.

### Синтез речи (TTS)

| Провайдер | Описание |
| --- | --- |
| Локальный (системный TTS) | По умолчанию; если движок явно не выбран, предпочтителен Google TTS, затем системный по умолчанию |
| OpenAI-совместимый | `POST {base}/v1/audio/speech`, адрес, модель и голос настраиваются |
| Huawei HMS (ML Kit) | Синтез **в облаке**, нужны сеть и API Key из AGC, первые 1 млн символов в месяц бесплатно; поддерживаются только китайский и английский |
| ElevenLabs | Список голосов локализован по языку |
| VOICEVOX | Только в сборке `full` |

Если в системе нет ни одного движка TTS, появляется диалог с двумя вариантами: установить Google TTS или открытый движок sherpa-onnx.

### Бэкенды и способы подключения

Поддерживаются три типа бэкендов, для голоса и для чата маршрут выбирается независимо:

| Тип | Протокол | Назначение |
| --- | --- | --- |
| Hermes Agent | HTTP (`/v1/runs` или `/v1/chat/completions`) | Основной; поддерживает системный промпт, потоковый вывод, сессии |
| Шлюз OpenClaw | Протокол узла WebSocket | Телефон подключается как узел, шлюз может напрямую присылать вызовы инструментов |
| OpenClaw HTTP | OpenAI-совместимый HTTP | Лёгкий канал, не требующий постоянного соединения |

- **Подключение для голосовой сессии** — один из трёх: `Шлюз OpenClaw` / `OpenClaw HTTP` / `Hermes HTTP`; переключатель есть и вверху «Голосового диалога» на главной, и в настройках; если вручную не выбирали, используется основной бэкенд.
- **Текстовый чат** смотрит на тип бэкенда, выбранный в сессии, а не на эту настройку.
- **Промпты**: у голосового и текстового чата свои системные промпты, их можно изменить в «Настройки → Чат»; если оставить пустыми, используются встроенные значения по умолчанию.
- **Голос передаёт контекст** — время, местоположение, заряд, сеть и состояние экрана отправляются с каждым голосовым запросом, поэтому ассистент может сразу ответить «который час» или «сколько заряда на телефоне».
- **Самовосстановление службы**: если привязка голосовой службы к системе потеряна, выполняются три уровня повторов — подтверждение ассистента по умолчанию, повторный запрос системной привязки и, в конце, перезапуск процесса.

### Управление телефоном (Mobile Bridge)

Телефон поднимает собственный локальный HTTP-сервис (по умолчанию 8787), через который Hermes обратно вызывает возможности телефона: чтение экрана и работа с интерфейсом (`screen.tap/swipe/long_press/drag/back/home`, `screen.find_nodes`, `screen.window.describe`), снимок экрана (двухэтапный, JPEG), фото, геолокация, SMS, контакты, календарь, чтение и очистка уведомлений, буфер обмена, управление медиа, громкость и яркость, список приложений и запуск.

- Одноразовая привязка: после включения моста в приложении появляется 6-значный код сопряжения, на компьютере по этому коду получают token, дальше сопряжение не нужно.
- Авторизация и подтверждения: права выдаются группами по возможностям, рискованные действия (отправка SMS, фото, работа с интерфейсом) требуют подтверждения в диалоге, кроме того действуют ограничения частоты.
- Включать рекомендуется только в локальной сети или в Tailscale; чтобы подключиться снаружи, в режиме привязки нужно выбрать LAN/VPN.
- **Это опциональный компонент**: при работе через шлюз OpenClaw сам шлюз умеет отдавать возможности телефона, и мост включать не нужно.

### Прочее

- **Терминал**: встроенный терминал подключается к Hermes dashboard на компьютере, требуется `hermes dashboard --tui`.
- **Задачи по расписанию**: просмотр, создание и редактирование cron-задач Hermes, можно указать скрипт (относительно `HERMES_HOME/scripts/`).
- **Диагностика**: и на главной, и в настройках есть предварительные проверки — отсутствие прав, непривязанная голосовая служба, ненастроенный бэкенд, выключенная доступность перечисляются по пунктам вместе с тем, где это исправить.
- **Тёмная тема**: весь интерфейс следует системной светлой/тёмной теме, включая мастер настройки.
- **10 языков интерфейса**: для каждого языка переведены все 1092 строки, английские вставки не появляются.

## Установка

Скачайте APK со страницы [Releases](https://github.com/pengtb/wakehermesclaw/releases) и установите напрямую (имя пакета `com.openclaw.assistant`).

После установки в приложении нужно сделать три вещи:

1. **Добавить бэкенд**: в «Настройки → Подключение» укажите адрес и token Hermes (или хост / порт шлюза OpenClaw).
2. **Назначить цифровым ассистентом**: сделайте это приложение ассистентом по умолчанию, иначе вызов удержанием панели навигации не сработает.
3. **Выдать права**: микрофон обязателен; геолокация, камера, SMS, контакты, календарь — по мере нужных возможностей; для управления телефоном дополнительно включите службу доступности.

Распознавание и синтез речи по умолчанию используют системные возможности — звук и распознавание работают и без настройки.

## Сопряжение

### Бэкенд Hermes

В `integrations/agentvoice-pair/` лежит утилита для десктопа: версии для PowerShell и bash эквивалентны и не требуют зависимостей (кодирование QR-кода и запись PNG реализованы в самих скриптах). Она определяет адрес Hermes API на этой машине (сначала Tailscale Serve, затем локальная сеть), API key, а также адрес Terminal в dashboard и session token — и генерирует QR-код для сопряжения:

```bash
bash install.sh                # ставится как agentvoice-pair; в Windows ставится .ps1 и создаётся обёртка .cmd
agentvoice-pair --open --svg   # сгенерировать QR-код и открыть
```

Внутри QR-кода — диплинк:

```
agentvoice://setup?hu=<адрес API>&hk=<key>&hm=<profile>&hr=1&hs=1&htu=<адрес dashboard>&htt=<session token>
```

`hu` / `hk` — адрес Hermes и API key, `hm` — целевой profile, `hr=1` означает использование Runs API по умолчанию, `hs=1` — потоковый вывод, `htu` / `htt` — адрес dashboard и session token для терминала. `hu` можно указывать несколько раз: несколько адресов проверяются параллельно, выбирается самый быстрый. На телефоне подойдёт любой из трёх путей: сканирование системной камерой (ссылка открывает приложение), сканирование внутри приложения или вставка этого JSON / диплинка прямо в мастер настройки.

В QR-коде лежат API key и session token — это равносильно паролю, не передавайте его наружу.

### Mobile Bridge

1. На телефоне откройте «Настройки → Mobile Bridge»: после включения страница показывает 6-значный код сопряжения и диплинк `agentvoice://pair?u=<адрес моста>&c=<код сопряжения>`.
2. На компьютере выполните `agentvoice-pair --code <код сопряжения> --write-env <путь>` или отправьте `POST {"code":"<код сопряжения>"}` на `http://<телефон>:8787/pair`.
3. Полученный token запишите в `.env` в `AGENT_VOICE_BRIDGE_URL` / `AGENT_VOICE_BRIDGE_TOKEN`; дальше каждый вызов отправляет заголовок `Authorization` со значением `Bearer` и этим token.

Код сопряжения одноразовый и имеет срок действия. После получения token сопряжение больше не нужно, но рискованные возможности — отправка SMS, фото, нажатия — по-прежнему требуют подтверждения при каждом вызове.

## Сборка из исходников

Нужны JDK 17 и Android SDK 35.

```bash
./gradlew assembleStandardDebug     # отладочный пакет (в имени пакета добавляется .debug, может стоять рядом с релизным)
./gradlew assembleFullDebug         # отладочный пакет с VOICEVOX
./gradlew assembleStandardRelease   # релизный пакет
```

Результат в `app/build/outputs/apk/<flavor>/<buildType>/`.

Несколько замечаний по сборке:

- `app/google-services.json` не хранится в репозитории. Без реальной конфигурации Firebase собирайте с `FIREBASE_ENABLED=false`, иначе Firebase инициализируется с mock-конфигурацией.
- Для release-сборки нужна локальная конфигурация подписи (`storeFile / storePassword / keyAlias / keyPassword` в `local.properties`).
- В release-сборке нужно исключить `uploadCrashlyticsMappingFileStandardRelease`, иначе она обратится к Firebase.
- R8 должен пропускать классы на стороне устройства, на которые ссылается HMS SDK (`com.huawei.libcore.*`, `org.chromium.net.*`); правила уже есть в `app/proguard-rules.pro`.
- Ключи Huawei подставляются в `BuildConfig` из `hms.asr.key / hms.asr.appid / hms.asr.cert` в `local.properties` и в репозиторий не попадают; в release-пакете нет ключа TTS, его нужно ввести в приложении самостоятельно.

## Что изменено относительно оригинала

Оригинал — `yuga-hashimoto/openclaw-assistant`. Изменения этого форка сгруппированы по функциям:

**Бэкенд Hermes**

- Hermes Agent подключён как полноценный бэкенд: работают и `/v1/runs`, и `/v1/chat/completions` — сессии, потоковый вывод, системные промпты. В Runs API системное сообщение обязано лежать в `instructions` верхнего уровня (из `input` сервер его не читает), и на клиенте это учтено.
- Способ подключения — один из трёх: шлюз OpenClaw / OpenClaw HTTP / Hermes HTTP; переключатель есть и на главной, и в настройках, выбор соблюдается строго, молчаливого отката больше нет.
- Если в адресе нет `/v1/`, он дополняется автоматически — исправлена ошибка 404 при первой же отправке сообщения после миграции старых настроек.

**Голос**

- Распознавание стало подключаемым, с несколькими бэкендами: системное / OpenAI-совместимое пакетное / потоковый FunASR / Huawei HMS; прежний бэкенд Baidu удалён.
- Добавлен облачный синтез Huawei HMS; если на устройстве нет ни одного движка TTS, показывается подсказка по установке.
- Системные промпты голоса и текстового чата разделены и редактируются; пустое значение откатывается к умолчанию.
- Голосовой запрос автоматически несёт время, местоположение, заряд, сеть и состояние экрана.
- Слова выхода: произнесённое слово сразу завершает текущую сессию, слова по умолчанию зависят от языка интерфейса.
- Плюс три способа вызова: плитка в быстрых настройках, переходная активность `VOICE_COMMAND`, статический шорткат.
- Потеря привязки голосовой службы к системе лечится тремя уровнями: подтверждение ассистента по умолчанию → повторный запрос привязки → перезапуск процесса.
- Панель стала карточкой, прижатой к низу, и больше не перекрывает строку уведомлений; уведомление во время диалога меняет текст при переходе в фон и обратно, нажатие возвращает к панели, после завершения оно исчезает.

**Управление телефоном**

- Снимок экрана и фото сделаны двухэтапными: сначала возвращаются метаданные и короткоживущий id, затем по id забирается base64; изображения хранятся только в памяти, истекают через 5 минут и не пишутся на диск.
- Фото снимается через foreground-службу камеры, которая «взводится» только после подтверждения, — так обходится запрет Android 12+ на запуск службы камеры из фона.
- Отправка SMS теперь ждёт результата `sentIntent` и возвращает настоящий код результата.
- Жесты доступности отправляются в главном потоке с ожиданием колбэка — исправлено молчаливое невыполнение tap / swipe; `screen.window.describe` берёт активное окно, имя пакета больше не определяется неверно.
- В группировку возможностей добавлены `location` / `screen`; карточка состояния моста показывает две строки — где мост доступен сейчас и где он будет доступен после применения настроек, так что конфигурацию можно сразу сверить.

**Повседневное использование**

- Предварительные проверки есть на главной, в настройках и в мастере: охватывают runtime-права и службу доступности, у каждого пункта есть «перейти и исправить».
- Переведены все 1092 строки для каждого из 10 языков интерфейса; языки выбираются в списке.
- Тёмная тема охватывает мастер настройки и страницу управления бэкендами.
- В терминал добавлены поля адреса dashboard и session token; в задачи по расписанию добавлена строка скрипта, а также исправлено падение десериализации всего списка задач interval / once из-за обязательного `expr`.
- Внизу страницы настроек показывается короткий хеш сборки — разные артефакты одного и того же номера версии можно различить.

Подробности изменений смотрите в `git log`; архитектурные компромиссы и набитые шишки описаны в `AGENT.md`.

## Известные ограничения

- `apps.launch` при запуске Activity из фона блокируется ограничениями фонового запуска Android 10+, вызов возвращает успех, но на переднем плане ничего не переключается.
- `brightness.set` требует `WRITE_SETTINGS`; без разрешения возможность не видна.
- Самосборный пакет (с другим именем) не получает модуль сканирования ML Kit из Google Play, сканирование внутри приложения недоступно; можно обойти, отсканировав QR-код диплинка системной камерой.
- Распознавание и синтез Huawei HMS поддерживают только китайский и английский.
- Каналы «шлюз OpenClaw» и «OpenClaw HTTP» негде было протестировать на сервере в окружении автора, проверки на реальном устройстве не проводились.
